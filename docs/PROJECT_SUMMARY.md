# Project Summary

GodsEye is an edge-based, self-learning IDS/IPS built with XDP/eBPF, Suricata, CNN-LSTM, ONNX Runtime, and FastAPI.

## Layers

- L0 Telemetry & Normalization
- L1 Feature Extraction
- L2 Behavioral Analysis
- L3 Threat Intelligence
- L4 DNS/TLS Analysis
- L5 WAF Analysis
- L6 CNN-LSTM Analysis
- L7 ONNX Inference
- L8 Decision Fusion
- L9 Response/Enforcement
- L10 Monitoring/Feedback
